## The problem

Salesforce is the most powerful business platform in the world, but working in it every day is harder than it should be. Users jump between tabs, list views and record pages to finish one simple task, and every jump costs time and focus.

- **Too many clicks.** Opening, updating and moving to the next record means repeated page loads.
- **Scattered work.** Records, approvals, notifications and team goals live on different screens.
- **Generic screens.** Standard layouts are built for every company, so they fit no team perfectly.
- **Costly customisation.** Making Salesforce feel right for one team usually needs custom development that is slow to build and hard to maintain.

The result is lower adoption, frustrated users and less value from a large Salesforce investment.

### Flagship: Yogi Workspace

Yogi Workspace puts everything a team needs on one screen. Admins choose up to six objects and six components per workspace; users get spreadsheet-fast lists, summary tiles, saved views, row colours and Kanban boards, and open any record in place to act on it and move to the next one without a page load. It is built as independent modules (Workspace, Record Views, Record Scroller, Record Display, Workspace Settings, and the My Approvals, Leaderboard and Notifications components), so each can be sold and adopted on its own.

## How we build

Every Yogi Labs product follows the same principles, so customers know what to expect from the next one.

- **Native first.** Lightning Web Components, Apex and standard Salesforce features before anything custom; no outside servers unless a product needs one.
- **Secure by default.** Data access runs in user mode, so sharing rules, field-level security and object permissions always apply. Admin settings are protected by a dedicated permission.
- **Modular.** Products are split into independent modules that talk through one message channel. Customers adopt one module at a time and we ship each one separately.
- **Fast.** Built for thousands of records, with instant sort, filter and search.
- **Accessible.** Keyboard navigation, screen-reader labels and WCAG 2.1 AA contrast.
- **Brandable.** Logo, colours and themes per workspace, or one org-wide brand.
- **Quality gates.** At least 90% Apex test coverage per class, Jest tests for every component, and Salesforce Code Analyzer clean before release.
- **AI where it helps.** AI features suggest and explain; the user stays in control and approves.
